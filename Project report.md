Customer Churn Analysis Project

 1. Introduction
Customer Churn Analysis is a data analytics project that studies customers who leave a company's services.

 2. Project Objective
The objective is to identify customer churn patterns and understand factors that may influence customers to leave.

3. Tools Used
- Microsoft Excel
- SQL (MySQL)
- Power BI (Dashboard Planning)

 4. Dataset Information
Total Records: 1000

Dataset columns include:
- Customer ID
- Gender
- Age
- Tenure
- Contract
- Monthly Charges
- Churn

 5. Key Analysis Results
- Total Customers: 1000
- Churned Customers: 270
- Retained Customers: 730
- Churn Rate: 27%
  
6. Key Findings
- 270 customers have left the company.
- 730 customers are retained.
- Month-to-month contracts have the highest churn count.
  
7. Business Recommendations
- Improve customer satisfaction.
- Offer special discounts to customers.
- Encourage long-term contracts.
- Identify reasons for customer churn.

8. Conclusion
This project helped me understand customer churn using data analysis. It demonstrates how data can support business decisions and improve customer retention.
