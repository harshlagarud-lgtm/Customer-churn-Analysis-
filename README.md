# Customer Churn Analysis

## Project Overview
This project analyzes customer churn to understand why customers leave a company.

## Tools Used
- Microsoft Excel
- SQL (MySQL)
- Power BI (Learning and Dashboard Planning)

## Dataset
Total Customers: 1000

## Key Findings
- Total Customers: 1000
- Churned Customers: 270
- Retained Customers: 730
- Churn Rate: 27%

## Objective
To identify customer churn patterns and help businesses improve customer retention.
